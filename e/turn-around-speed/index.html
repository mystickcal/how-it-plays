Turn-around speed

Also called: turn acceleration, skid, quick turn, reverse acceleration

Give turning around its own, stronger acceleration so reversing is quick even when stopping is gentle.

←→ or AD move · Space W ↑ or Z jump

Try this: Run one way, then press the other way. Watch the skid dust and the turn time in the readout.

What it does

Many controllers use the stopping deceleration when the player reverses, so a soft stop also means a slow, skidding turn. Splitting the turn out gives one more knob: when input points against the current speed, use a separate, larger turn acceleration. The character keeps its gentle stop and still changes direction quickly.

Use it when

Characters that should feel nimble but not stop on a dime.

Watch out

A heavy character with a deliberate skid wants the slow turn.

Starting values

No checked source gives a separate turn number. Game Maker's Toolkit notes that Madeline changes direction very quickly with no skidding, and Celeste's code uses its full run acceleration when turning. Try 2 to 3 times your normal acceleration.

Prompt for your coding agent

The numbers follow the sliders above. Works with plain canvas, Phaser, Three.js or Godot.

Give turning its own acceleration.
- When horizontal input points opposite to the current horizontal speed, move speed toward the target at 4000 px/s² instead of the normal deceleration.
- Stopping with no input still uses the normal deceleration.
- Optional: spawn skid dust while turning.

Acceptance checks:
1. Reversing from full speed takes less time than before. Log both.
2. Releasing input still slides to a stop as before.
3. Same result at 30 and 144 fps.
